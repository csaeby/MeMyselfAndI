# Hi, I'm Christian 👋

I'm a senior software engineer and technical lead based in Stockholm, specializing in C#, .NET, Microsoft Azure, solution architecture, and applied AI.

This site is an interactive version of my CV and portfolio. It presents my experience, skills, education, interests, and contact details as a first-person 3D exhibition that you can explore using your keyboard and mouse. Each station in the gallery covers a different part of my background.

For a more traditional experience, the site also includes a clean 2D CV view that can be printed or saved as a PDF.

The site is built with JavaScript, Three.js, CSS and a healthy amount of vibesss!
